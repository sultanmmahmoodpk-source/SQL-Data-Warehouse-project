# 📊 Data Warehouse & Analytics Project

Welcome to the **Data Warehouse and Analytics Project** repository! 
This project demonstrates an end-to-end data warehousing and business intelligence solution using **Microsoft SQL Server**—from creating staging environments and transforming raw data via T-SQL to building an optimized Star Schema and generating actionable business insights.
---
## 🎯 Project Overview

The objective of this project is to build a scalable, modern Data Warehouse using SQL Server that consolidates multi-source business data into a single source of truth. It covers full ETL processing, T-SQL data cleaning, dimensional modeling (Star Schema), and interactive reporting.

### Key Highlights
- **100% SQL Server & T-SQL Based:** Complete ETL processing natively handled via SQL Server scripts, Stored Procedures, and Views.
- **Dimensional Data Modeling:** Designed Fact and Dimension tables using Star Schema methodology for high-performance analytical queries.
- **Data Quality & Validation:** Robust T-SQL scripts to handle missing values, duplicate records, and data type casting.
- **Analytics & BI Dashboard:** Interactive visualization connected directly to the SQL Server Data Warehouse.
